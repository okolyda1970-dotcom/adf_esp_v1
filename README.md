# ADF4350 Controller — ESP32-C3 (PlatformIO)

Управление синтезатором частот ADF4350 от ESP32-C3 через SPI.

## Распиновка

### ADF4350 (SPI)
| ESP32-C3 | ADF4350 | Назначение |
|----------|---------|------------|
| GPIO7    | SDATA   | SPI MOSI (данные) |
| GPIO6    | SCLK    | SPI Clock |
| GPIO3    | LE      | Latch Enable |
| GPIO1    | CE      | Chip Enable |
| GPIO2    | MUXOUT  | Lock Detect (вход) |

### Дисплей I2C (OLED SSD1306)
| ESP32-C3 | Дисплей | Назначение |
|----------|---------|------------|
| GPIO9    | SDA     | I2C Data |
| GPIO8    | SCL     | I2C Clock |

### Периферия
| ESP32-C3 | Назначение |
|----------|------------|
| GPIO0    | ADC — измерение батареи |
| GPIO4    | Кнопка 1 (пред. частота) |
| GPIO5    | Кнопка 3 (след. частота) |
| GPIO10   | LED индикатор |
| GPIO18/19| USB |

### Питание
| ADF4350 | Источник |
|---------|----------|
| AVDD    | 3.3V |
| DVDD    | 3.3V |
| GND     | GND |

## Структура файлов

```
platformio.ini          — конфигурация PlatformIO
include/
  adf4350.h             — драйвер ADF4350 (пины, параметры)
src/
  main.cpp              — основной код (кнопки, дисплей, LED, ADC)
  adf4350.cpp           — реализация SPI-драйвера
```

## Функционал

- ✅ SPI-драйвер ADF4350 (CPOL=0, CPHA=0, 10 МГц)
- ✅ Расчёт регистров: `RFout = PFD × (INT + FRAC/MOD)`
- ✅ OLED дисплей (SSD1306 128x64 I2C) — показывает частоту, lock, батарею
- ✅ Кнопки для переключения частот
- ✅ LED индикатор (горит при PLL lock)
- ✅ Измерение напряжения батареи через ADC
- ✅ Serial-команды

## Serial команды (115200)

| Команда | Описание |
|---------|----------|
| `f435.0` | Установить частоту 435.0 МГц |
| `l` | Проверить статус PLL lock |
| `b` | Измерить батарею |
| `r` | Показать все регистры |

## Кнопки

- **Button 1 (GPIO4)** — предыдущая частота из таблицы
- **Button 3 (GPIO5)** — следующая частота из таблицы

## Таблица частот

```cpp
144.0, 145.5, 430.0, 435.0, 438.0, 915.0, 1296.0, 2400.0 МГц
```

Меняй в `src/main.cpp` — массив `freq_table[]`.

## Сборка в VS Code + PlatformIO

1. Открой папку проекта в VS Code
2. Установи расширение PlatformIO IDE
3. Подключи ESP32-C3 по USB
4. В `platformio.ini` раскомментируй и укажи свой порт:
   ```ini
   upload_port = COM3    ; или /dev/ttyACM0 на Linux
   ```
5. Build: `Ctrl+Alt+B` или кнопка ✓ внизу
6. Upload: `Ctrl+Alt+U` или кнопка → внизу
7. Serial Monitor: `Ctrl+Alt+M`

## Формула частоты

```
RFout = PFD × (INT + FRAC / MOD)
PFD   = REF × (1 + Doubler) / (R × (1 + Div2))
```

## Диапазон ADF4350

- Выход: 34.6 – 4400 МГц
- PFD: до 32 МГц
- SPI: CPOL=0, CPHA=0, макс 20 МГц
- Питание: 3.0–3.6V
